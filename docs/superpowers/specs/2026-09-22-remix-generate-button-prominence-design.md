# 改编台词生成按钮辨识度设计

## 目标

让用户进入“改编脚本与语义区间”弹窗后，能够立即理解：先填写新主题，再点击按钮生成改编台词。

## 界面调整

- 保留现有“新主题”输入框与右侧按钮的紧凑横向布局。
- 将按钮文案从“按蓝图生成”改为“生成改编台词”。
- 使用项目现有青色主按钮样式，提高它在弹窗中的操作层级。
- 在输入区域补充短提示：“填写新主题后，点击右侧按钮生成台词”。
- 新主题为空、正在生成或正在保存时，按钮保持禁用；填写有效主题后恢复主按钮状态。

## 行为边界

- 不改变生成接口、蓝图继承、脚本保存和语义事件生成逻辑。
- 不调整改编台词文本框、语义事件区域或保存按钮。
- 保留键盘操作和现有无障碍名称。

## 验证

- 组件测试验证新按钮文案、禁用状态和点击生成行为。
- 运行相关改编流程集成测试和 TypeScript 检查。
- 在本地浏览器中确认按钮视觉层级、提示文案和弹窗布局。
