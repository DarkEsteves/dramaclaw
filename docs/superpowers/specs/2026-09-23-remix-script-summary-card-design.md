# 改编脚本小节点摘要卡设计

## 目标

让画布上的改编脚本节点优先回答三个问题：当前主题是什么、素材准备到哪一步、下一步做什么。完整台词仍可预览，但不再占据节点的主要视觉空间。

## 展示结构

节点沿用现有尺寸、标题、端口和工具条，只调整改编脚本模式下的内容区：

1. 顶部保留“参考改编脚本 · 版本 N”状态。
2. 主题行显示当前新主题；主题为空时显示“尚未填写改编主题”。
3. 摘要标签显示语义事件总数、必需 B-roll 完成数/总数。
4. 台词区域只显示两到三行预览，超出内容截断。
5. 底部继续显示现有下一步状态，例如“下一步：补齐必需 B-roll”。

## 数据规则

- 主题读取节点的 `remixTopic`。
- 事件数读取 `remixScriptDraft.selections.length`。
- 必需 B-roll 总数读取 `remixBrollRequirements` 中 `required` 为真的项目数。
- 已完成数按对应事件同时存在 `visualNodeId` 和 `visualMediaRevision` 计算。
- 没有必需 B-roll 时显示“B-roll 无必需项”，不显示 `0/0`。
- 原有三个普通脚本入口及其结果展示不受影响；摘要卡只用于参考改编脚本模式。

## 视觉与交互

- 使用项目现有暗色表面、弱边框、圆角和文字层级，不新增设计变量。
- 摘要标签使用现有弱化标签风格，不增加新的按钮。
- 点击节点和工具条行为保持不变；编辑仍从工具条进入。

## 验证

- 覆盖有主题、无主题、有必需 B-roll、无必需 B-roll及部分完成状态。
- 验证普通脚本节点展示未改变。
- 运行相关组件测试和 TypeScript 检查。
