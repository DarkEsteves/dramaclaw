# 参考视频改编：画布操作与本地运行

这条流程把参考视频的画面与台词拆成可核对的事件，再生成新主题脚本、绑定旁白和替换画面，最后从同一份合成清单预览并导出 MP4。当前版本适合固定素材演示和流程验收；真实语音的生产准确率仍需代表性样片与人工边界验收，详见[实施状态](../../experiments/reference-video-remix-implementation-status.md)。

## 开始前准备

- 项目环境已经执行 `uv sync --group dev`，机器上可用 `ffmpeg` 和 `ffprobe`。
- 已按[配置模型供应商](../getting-started/configuring-models.md)接入可用的文本模型网关。原片结构分析、按蓝图生成脚本和 B-roll 规划需要文本模型。
- 需要自动转写或“按脚本对齐”时，另行准备独立 WhisperX Python、离线模型缓存和 NLTK `punkt_tab`。仓库不附带这些权重，也不会在任务运行时下载。
- 本地开发直接在仓库根目录运行 `scripts/start-remix-speech.sh`。看到 `Speech engine is ready` 后保持该终端运行；另开终端启动前端。完整变量和探活方式见[本地语音引擎试运行](../../experiments/reference-video-remix-speech-setup.md)。
- 当前验收范围是 **15–60 秒**成片，输出固定为 H.264 MP4、1080×1920、30 fps，带 AAC 音轨。最终时长由旁白决定且不能超过 60 秒；少于 15 秒的素材可用于局部调试，但不在发布样片验收范围。
- 单文件上限 500 MiB。视频支持 `.mp4`、`.mov`、`.mkv`、`.webm`；音频支持 `.mp3`、`.m4a`、`.wav`、`.aac`、`.ogg`、`.flac`；图片支持 `.png`、`.jpg`、`.jpeg`、`.webp`。

本地开发可用下面两个终端启动：

```sh
# 终端 1：带离线 WhisperX 的 API
scripts/start-remix-speech.sh

# 终端 2：前端热更新
cd frontend
pnpm install
pnpm dev
```

浏览器打开前端地址，新建或进入一个项目的自由画布。执行写入和提交的账号需要该项目的 editor 权限；分布式部署还要求请求落到项目 home node。

## 从空白画布完成一次改编

1. **上传并分析参考视频。** 在自由画布点左下角 `+`，添加“视频”节点并上传文件。选中视频节点，点顶部 `分析原片`。系统会自动连出“原片拆解”节点；顶部按钮会显示 `继续改编 · 等待原片分析`，完成后变为下一步。
2. **核对拆解并生成脚本。** 在“原片拆解”中查看每个事件的时间、画面证据、台词证据和叙事作用。需要修正时展开 `参考蓝图与分析设置`，把不确定项核对为已审核；然后点 `生成改编脚本`，或点顶部 `继续改编 · 确认分析并生成脚本`。蓝图在这一步自动保存版本，不需要额外的“保存蓝图”动作。
3. **填写新主题与语义区间。** 在“改编脚本与语义区间”面板填写 `新主题`，点 `按蓝图生成`。修改 `改编台词` 后，在文本框中选中需要替换画面的词句，点 `标记选中文本`。为每个区间填写事件名称，并点面板底部 `保存脚本版本`。
4. **规划并补齐 B-roll。** 选中脚本节点，点 `继续改编 · 规划 B-roll`。有“必需 B-roll”提示的区间必须有实际画面：在该区间点 `生成` 或 `上传`，等素材节点完成后，在 `B-roll 画面` 中选中它并再次 `保存脚本版本`。素材节点必须与脚本保持连线；只创建空节点不算完成绑定。
5. **准备旁白。** 点 `继续改编 · 创建旁白节点`。单人台词可在音频节点选择音色生成，也可直接上传录好的音频；多人台词按角色选择各自音色后再生成。没有语音供应商时，直接上传一条与最终脚本逐字一致的旁白即可。
6. **对齐台词。** 选中旁白节点，点 `继续改编 · 按脚本对齐旁白`。系统会连出“转写与对齐”节点。完成后先通读合并台词；需要逐词检查时点 `展开逐词校对`，点击任一词可跳到对应声音。只改同一发音的错字时勾选 `仅校正同一发音和词边界，保留原时间`，再点 `保存校字`。
7. **生成语义时间轴。** 点 `继续改编 · 生成语义时间轴`，然后在时间轴节点点 `重新编译`。可按事件填写语义偏移、最短帧数或固定起止帧；修改后再次 `重新编译`。存在未解析的必需事件或固定时间冲突时不能继续导出。
8. **添加成片背景。** 点 `继续改编 · 添加成片背景 / A-roll`，在新素材节点上传最终成片使用的图片或视频，再点 `继续改编 · 绑定成片背景 / A-roll`。参考视频默认只作分析证据，不会自动进入成片。
9. **生成清单并导出。** 点 `继续改编 · 创建成片清单`，再点 `继续改编 · 生成合成清单`。合成节点显示 `预览与导出一致` 后可点 `导出 MP4`。完成后可使用 `预览成片`、`下载 MP4`、`下载 JSON` 和 `下载 SRT`。对清单做手工修改时，先点 `保存清单修改`，再导出该版本。

顶部 `继续改编 · …` 始终定位到这条链路的下一项未完成工作；需要回改时，也可以直接选中对应节点使用节点内按钮。等待中的任务无需反复点击，刷新页面后会按原任务 ID 恢复检查。

## 常见阻塞与恢复

| 页面提示 | 处理方式 |
| --- | --- |
| `当前视频没有声音，无法转写`、`没有识别到人声` | 参考片无音轨时不要对它点“转写”；完成脚本后在旁白节点生成或上传清晰人声。文件有音轨但仍无结果时，先确认语言和实际人声，再点 `重新转写` 或 `按脚本对齐`。若提示语音引擎未配置，使用 `scripts/start-remix-speech.sh` 启动并检查探活。 |
| `脚本与音频不一致` | 在“转写与对齐”节点点 `校对台词`，让保存的脚本与实际发音逐字一致；或重新录制/生成旁白。随后点 `重新对齐`。不要用“保存校字”把增删台词伪装成同音纠错。 |
| `补齐必需 B-roll`、`素材已变化` | 回到脚本编辑面板，为对应语义区间点 `生成`/`上传`，等素材完成后重新选择 `B-roll 画面` 并点 `保存脚本版本`。素材被替换或删除后必须重新绑定当前版本。 |
| `台词已改变，请重新标记这个区间` | 在改编台词中重新框选完整词句，点 `标记选中文本`，删除失效的旧区间后保存脚本版本。 |
| `上游已变化，更新清单`、`预览已过期` | 点 `更新清单`。若出现手工修改冲突，逐项选 `保留手工值` 或 `采用上游值`；无法安全保留时采用上游值。点 `保存清单修改`，待状态变为 `预览与导出一致` 后重新导出。 |
| 导出一直处于恢复确认 | 先点 `重新检查任务`。确认旧任务已失败或结果已过期后，才点 `强制重新导出`；不要刷新后立即重复提交。 |

## 操作者交接检查

交付演示前确认：参考拆解事件均已核对；脚本、旁白、对齐和时间轴显示当前版本；每个必需 B-roll 都连接实际素材；背景是明确选择的成片画面；合成节点没有未解析事件或冲突；预览状态为 `预览与导出一致`；下载的 MP4 为 1080×1920/30 fps 且从开头到结尾都有旁白音轨。

这份检查只证明画布链路和固定媒体产物可用。上线真实语音前，还必须补齐中英文各至少 100 个人工边界、授权素材清单、权重许可证，以及目标机器上的 P95、耗时、内存和并发数据。
