# 画布深度动作捕捉入口

视频节点工具条的“深度动作捕捉”入口会创建一个普通视频节点，连接当前视频，预选深度模型和现有的视频编辑模式。入口不会自动生成；用户可以调整参数、查看积分报价，再确认提交。

## 配置模型目录

在深度视频模型的现有 `config` 中设置用途标记和输入能力：

```json
{
  "processingKind": "depth",
  "supportedModes": ["video_edit"],
  "referenceVideoMax": 1,
  "referenceImageMax": 0,
  "referenceAudioMax": 0,
  "supportsGenerateAudio": false
}
```

入口通过 `processingKind: "depth"` 查找模型，模型还必须支持视频编辑且允许视频输入。显示名称、模型目录 ID 和网关模型别名可以独立配置，无需匹配固定名称。有多个可用的深度模型时，入口使用目录中的第一个匹配项。

模型目录响应需保留该用途标记；前端同时接受 `processingKind` 和 `processing_kind`。模型的分辨率、专用参数及其请求映射继续通过现有配置管理，入口不写入模型特有参数。

## 可用性与计费

- 当前节点没有视频素材时，入口置灰并提示先上传视频。
- 模型目录加载中、不可用或没有匹配模型时，入口置灰并显示相应原因。
- 点击入口后，用户仍通过普通视频节点提交，使用现有视频编辑接口和参数结构。
- 报价与扣费沿用 `freezone.video_generate` 和对应媒体模型价格规则；入口没有独立计费规则。

用户也可以自行创建普通视频节点，连接视频素材并选择该模型。
