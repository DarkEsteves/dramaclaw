# Agent 执行边界记录

## 当前行为

- 普通对话由主 Agent 直接理解和组织内容，不为每条消息启动额外意图识别请求。
- 方案和素材工作包保留当前保存引用；失败时工具结果带回错误码、字段路径、阶段、当前 work_ref 和下一步修正动作。
- 如果错误响应已经包含当前 work_ref，Agent 继续修正同一工作包；没有引用时先读取当前工作包，不能创建新的工作包。
- 请求被拒绝且没有保存引用时，结果才标记为无副作用。
- 生成、候选验收、画布写入和其他不可逆动作仍走原有审核、用户确认和动作执行确认。
- 不自动重试、不自动创建下一阶段、不自动切换模型或渠道。
- 工具失败保持卡片级失败样式，普通 Agent 聊天保持普通样式。

## 硬规则

4～15 秒、真实方案和素材引用、当前 revision、权限范围、用户确认和幂等提交仍由后端在执行边界检查。Agent 可以自由安排段落、镜头、动作、节奏、提示词和修正顺序，但不能用自由文本替代这些确定性凭据。

## 验证

本次回归覆盖 Freezone 工具错误传递、作品方案失败详情、素材执行、方案多阶段、原片制作通知、聊天卡片呈现、TypeScript 编译和交互工具同步检查。
