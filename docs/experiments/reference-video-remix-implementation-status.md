## 画布可操作切片（本轮补充）

- 在“视频合成”节点点击“参考视频改编”，上传项目内参考视频及可选旁白，可选中文/英文自动识别字幕并修改台词时间和关键时刻，也可手动填写；关键时刻可上传替换画面。
- 上传返回不可覆盖的项目相对路径、SHA-256、时长与音轨信息；合成清单绑定媒体哈希。画布提交后可查询任务、播放或下载成片；刷新后可从同节点的生成记录找回任务。结果确认会核对节点和清单版本，过期结果保留在历史中。
- 本机已将 WhisperX 3.8.6 安装在独立虚拟环境，缓存中文/英文 ASR 与对齐权重，通过子进程连接项目服务；其他机器仍需按 [语音服务配置](reference-video-remix-speech-setup.md) 准备环境。未配置语音引擎的服务返回 503。
- 用本机合成中文语音和 FFmpeg 视频在浏览器中完成上传、自动识别字幕、编辑回填、渲染和成片回填；英文语音在本地适配器完成逐字对齐。真实素材的质量与耗时尚未验收。

## 尚未通过的验收门槛

1. **P0 真实语音验收受输入阻塞。** 用户确认当前没有代表性视频/旁白和人工标注。没有中文、英文各至少 100 个手工边界，无法测 P95 对齐误差、两版语速事件移动、真实 CPU/GPU 耗时与内存，因此不能选定生产 ASR 引擎或并发限额。本机语音引擎仅供试用。
2. **编辑能力仍是基础切片。** 自动转写后的字幕可在画布中校字和改时间；定时替换画面也可操作。转写正文现可点词定位播放并随播放高亮当前词。修改脚本后的强制重新对齐、成片字幕逐词高亮、淡入淡出与缩放、精确预览仍待实现。浏览器端真实素材验收未做。
3. **自动编排仍未闭环。** Workflow 已能描述 typed 处理输入，但尚未把这些描述符接到现有审批/任务/计费完整链路。Recipe v2 的结构交付已接入文本成功路径，其他创作动作与局部重跑、刷新恢复仍需实现。
4. **局部重跑和结果复用未完成。** 已有按节点版本确认和结果回填，但改编 Recipe 的完整自动编排、跨节点协同与历史结果复用仍待实现。
5. **真实效果尚未验收。** 隔离本机已有模型配置后，全库测试结果为 6427 passed、19 skipped、3 deselected；手工合成样例已通过画布导出。仍需要真实样片和模型验收识别精度、素材替换效果与并发表现。

## 下一轮验收输入

- 六类代表样片与合法使用来源；中文和英文清晰语音各至少 100 个手工时间边界，另含重复词、无语音、漏词/增词、可变帧率和剪切变速。
- 目标运行机器的 CPU/GPU、内存、期望并发与模型权重存放方式。
- 对固定素材样片逐项核对输出画幅、字幕时序、音轨连续、事件移动和导出耗时，然后决定生产 SpeechAligner 的版本与安装方式。

在 P0 数据到位前，可以继续修复现有基础切片；不能宣称真实对齐准确率或完整用户路径已经验收。
